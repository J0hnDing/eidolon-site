# Eidolon Site

The public product website for Eidolon and Eidolon Atlas. It explains the local-first product model, capability lifecycle, trust boundaries, and Atlas, with dedicated privacy and terms pages.

## Development

```powershell
npm install
npm run dev
```

Open `http://127.0.0.1:5173/`.

## Validation

```powershell
npm run lint
npm run build
```
